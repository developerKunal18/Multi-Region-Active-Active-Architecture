🧠 What Is Active-Active?

In a normal single-region application:

                 Users
                   │
                   ▼
              Load Balancer
                   │
                   ▼
              Region 1
                   │
            ┌──────┴──────┐
            ▼             ▼
         Flask         Database

If Region 1 goes down:
Users
  │
  ▼
❌ Region 1

With Active-Active:

                         Users
                           │
                           ▼
                    Global DNS / LB
                      /           \
                     /             \
                    ▼               ▼
              Region A          Region B
              Mumbai            Singapore
                 │                 │
              Flask             Flask
                 │                 │
                 └───────┬─────────┘
                         ▼
                  Distributed Data

Both regions are active at the same time.

🎯 Goals

The architecture should provide:

✅ High availability
✅ Geographic redundancy
✅ Low latency
✅ Automatic failover
✅ Horizontal scalability
✅ No single application region dependency
